# vis env

Prints what vis sees from the current directory: the Node version and platform, the directory, the workspace root, and the package manager it would use. It changes nothing.

If the workspace is not found from this directory, `vis env` says so. vis treats the directory it runs from as the workspace root, so run it from the root of the workspace.

## Usage

```bash
vis env
```
