# vis test

Runs the project's tests with [Vitest](https://vitest.dev). It needs no `test` script in `package.json` and no `vis.config.ts` entry: it finds the `vitest` install in the nearest `node_modules` (walking up from the current directory, so a hoisted install works from a workspace package) and runs it.

Vitest is not bundled. Add it to your project first:

```bash
vis add -D vitest
```

## Usage

```bash
vis test [files…] [options]
```

Positional arguments and any other flags are forwarded to Vitest unchanged.

## Examples

```bash
# Run all tests once
vis test

# Re-run tests on change (Vitest's watch mode)
vis test --watch

# Run a single test file
vis test src/foo.test.ts

# Forward flags to Vitest
vis test -- --reporter=dot
```

## Exit codes

The exit code is Vitest's: `0` when every test passes, non-zero otherwise.
